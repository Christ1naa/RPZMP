 # Лекція 2 — Основи Kotlin

## Основне
- `val` — значення не переприсвоюється; `var` — можна змінювати.
- Тип указуємо явно або Kotlin визначає його з початкового значення.
- `Int` — ціле число; `Double` — дробове; `Boolean` — `true` або `false`.
- `Char` — символ у одинарних лапках; `String` — текст у подвійних.
- `print()` — без переходу на новий рядок; `println()` — із переходом; `\n` — новий рядок.
- Шаблони рядків: `$name` — значення змінної; `${number > 0}` — результат виразу.
- `readln()` читає текст; `.toInt()` та `.toDouble()` перетворюють його на число.
- Арифметика: `+`, `-`, `*`, `/`, `%` (остача). `5 / 2` → `2`; `5.0 / 2` → `2.5`.
- `=` — присвоєння; `==` — рівність; `>` і `<` — порівняння. Результат перевірки — `Boolean`.
- Парність: `number % 2 == 0`; нуль також парний.
- `if / else` обирає гілку: використано для перевірки дільника на нуль.
- `x += 2` означає `x = x + 2`; `++` і `--` змінюють значення на 1.
- Порозрядні операції: `shl`, `shr`, `ushr`, `and`, `or`, `xor`, `inv()`.

## Контрольні запитання
1. Точка входу — `main()`.
2. `main(args: Array<String>)` отримує аргументи командного рядка; `main()` — без параметрів.
3. Коментарі: `// ...`, `/* ... */`; документаційні — `/** ... */`.
4. `val` не дозволяє переприсвоєння; `var` дозволяє.
5. Цілі типи: `Byte`, `Short`, `Int`, `Long`; без знаку — `UByte`, `UShort`, `UInt`, `ULong`.
6. `val pi: Float = 3.14F` (або `f`).
7. `Boolean` приймає `true` або `false`.
8. `val name: String = "Андрій"`.
9. Основні операції: `+`, `-`, `*`, `/`, `%`; також `++`, `--`.
10. `%` повертає остачу: `7 % 2` → `1`.
