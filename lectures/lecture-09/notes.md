# Лекція 9 — Перерахування, делегування та анонімні об'єкти

## Основне

- `enum class` описує скінченний набір пов'язаних констант: `enum class Operation { ADD, SUBTRACT, MULTIPLY }`.
- Кожна enum-константа є об'єктом цього enum-типу; константи можуть мати властивості конструктора та власну поведінку.
- Якщо після переліку констант є методи або властивості в тілі enum-класу, перелік завершують `;`.
- `name` — точна назва константи; `ordinal` — її позиція, починаючи з нуля. Власне числове поле конструктора не дорівнює `ordinal` автоматично.
- `Day.values()` повертає масив констант; `Day.valueOf("FRIDAY")` шукає за точною назвою з урахуванням регістру. Невідома назва спричиняє `IllegalArgumentException`.
- У сучасному Kotlin для перебору також є `Day.entries` (Kotlin 1.9+). У файлі залишено `values()`, як у PDF, для сумісності з попередніми версіями.
- Enum може реалізувати інтерфейс; окремі константи можуть перевизначати абстрактні властивості та методи.
- `when` за enum зручний для вибору операції або реакції на стан. Якщо оброблено всі константи, `else` не потрібен.
- Делегування передає реалізацію контракту іншому об'єкту: `class SmartPhone(m: Messenger) : Messenger by m`.
- `by m` у списку супертипів делегує публічні члени інтерфейсу `Messenger`; це не успадковування від конкретного класу делегата.
- Можна делегувати різні інтерфейси різним об'єктам: `Messenger by m, PhotoDevice by p`.
- Власний `override` методу або властивості замінює делегування відповідного члена. Решта викликів і далі передаються делегату.
- Делегат усередині своїх методів використовує власні члени: перевизначення властивості в обгортці не змінює стан делегата.
- `object { ... }` — вираз, який створює анонімний об'єкт із властивостями й методами.
- `object : Person("Тарас") { override fun sayHello() { ... } }` створює анонімний підклас. Можна також реалізовувати інтерфейси.
- Анонімний об'єкт можна передати аргументом або повернути з функції. Доступні члени залежать від видимості функції та оголошеного/виведеного типу результату.

## Приклади з `tasks.kt`

Це **навчальні приклади за змістом PDF**, а не окремо сформульовані викладачем практичні завдання. Окремого переліку завдань чи контрольних запитань у PDF немає.

1. `Day`: конструктор, метод, `name`, `ordinal`, `values()` і `valueOf()`. Для п'ятниці `ordinal = 4`, а власний `number = 5`.
2. `DayTime : Printable`: константи з власними реалізаціями абстрактних властивостей і методу інтерфейсу.
3. `Operation` та `operate()`: вичерпний `when`; для 5 і 6 результати — 11, -1, 30.
4. `SmartPhone`: делегування методів і властивості `programName` об'єкту `InstantMessenger`, а `takePhoto()` — об'єкту `PhotoCamera`.
5. `CustomPhone`: власні `programName` та `send()`, але делегований `sendVideo()`. Текст друкується як SMS, відео — як Telegram, оскільки це реалізація делегата.
6. Локальний анонімний об'єкт, анонімний підклас як аргумент `hello()`, результат приватної `createProfile()` та публічної `createPerson(): Person`.

## Питання для самоперевірки

Навчальні питання з короткими відповідями, додані для повторення.

1. Коли enum кращий за рядок? Коли допустимі лише визначені значення: компілятор перевіряє їхній тип.
2. Чи варто зберігати `ordinal` як незмінний код? Ні: перестановка констант змінить його; краще окрема властивість `code`.
3. Що станеться з `Day.valueOf("friday")`? Помилка: оголошено `FRIDAY`, регістр має значення.
4. Що означає `Messenger by m`? Об'єкт реалізує контракт Messenger через передавання викликів об'єкту `m`.
5. Чи припиняє один `override` усе делегування? Ні, він замінює лише відповідний член.
6. Чому `CustomPhone.sendVideo()` друкує Telegram? Метод виконує делегат і читає своє `programName`.
7. Чим анонімний об'єкт відрізняється від лямбди? Об'єкт може мати кілька властивостей і методів та успадковувати клас; лямбда описує функцію.
8. Чому `createPerson(...).company` недоступна? Тип результату — `Person`; додаткова властивість анонімного підкласу до його контракту не входить.

## Що запам'ятати та уточнення до PDF

- Різниця `FRIDAY.number - MONDAY.number` — різниця номерів у межах тижня. Це не універсальний розрахунок тривалості з переходом через неділю.
- Нічний діапазон 22–5 переходить через північ; він показує властивості enum, а не готовий алгоритм перевірки часу.
- §4.13.3 демонструє **делегування властивостей інтерфейсу** через `Messenger by m`. Механізм окремих делегованих властивостей `val x by ...` — інша тема; у цій лекції його не розглянуто.
- Для локального анонімного об'єкта та результату приватної не-inline функції з виведеним типом доступні власні члени. Якщо явно вказати тип `Person`, залишиться лише контракт `Person`, навіть для приватної функції.
- Для публічного результату анонімного об'єкта без явного типу видимим типом стає `Any` або єдиний оголошений супертип; додаткові члени не доступні. З кількома супертипами тип результату потрібно вказати явно.
- Фрагмент PDF із `private inline` не потрібен для цих прикладів. Для передбачуваного зовнішнього API використовуйте явний іменований тип результату, як у `createPerson(): Person`.
