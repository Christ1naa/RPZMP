# Лекція 5 — Анонімні функції та лямбди

## Основне
- Функцію можна зберегти у змінній, передати як аргумент або повернути з іншої функції.
- `(Int, Int) -> Int` — тип функції: приймає два Int і повертає Int.
- Анонімна функція: `fun(x: Int, y: Int): Int = x + y`.
- Лямбда: `{ x: Int, y: Int -> x + y }`.
- Результат лямбди — її останній вираз; `println()` повертає Unit.
- Типи параметрів можна пропустити, якщо вони відомі з контексту.
- Trailing lambda — останній аргумент-лямбду можна винести за круглі дужки.
- `_` — невикористаний параметр.
- Коротку одноразову дію зручно записати лямбдою; складну або повторювану — іменованою функцією.

## Завдання — класи та конструктори
Усі три завдання виконані в одному `tasks.kt`.
- Клас Car має властивості brand і year.
- Первинний конструктор приймає марку та рік.
- Вторинний конструктор розташований у тілі класу:
  `constructor(brand: String) : this(brand, 2026)`.
- `Car("Toyota", 2020)` — виклик первинного конструктора.
- `Car("Ford")` — виклик вторинного; рік буде 2026.
- Доступ до властивостей: `car.brand`, `car.year`.
- Введення з консолі за умовою не потрібне.

## Контрольні запитання
1. Клас — опис властивостей і поведінки; об’єкт — конкретний екземпляр класу зі своїми даними.
2. Клас оголошують через `class`: `class Car(val brand: String, val year: Int)`.
3. Клас визначає структуру, а об’єкт створюється за цією структурою. Один клас може мати багато об’єктів.
4. Об’єкт створюють викликом конструктора: `val car = Car("Toyota", 2020)`.
5. Конструктор задає початкові дані об’єкта під час його створення. Є первинний і вторинні конструктори.
6. Первинний конструктор записують після назви класу: `class Car(val brand: String, val year: Int)`. `val` або `var` робить його параметри властивостями об’єкта.
