# Лекція 4 — Функціональне програмування

## Основне
- Параметр оголошується у функції: `name: String`; аргумент передається під час виклику: `greet("Олена")`.
- Значення за замовчуванням: `age: Int = 18`; цей аргумент можна пропустити.
- Іменовані аргументи: `printUserInfo(age = 25, name = "Олена")`.
- Параметри не можна переприсвоювати, але елементи переданого масиву можна змінювати.
- `vararg` приймає довільну кількість аргументів одного типу.
- `*values` передає елементи масиву у `vararg` як окремі аргументи.
- `return` повертає результат і завершує поточний виклик функції.
- `Unit` — тип результату функції, яка не повертає корисного значення.
- Однорядкова функція: `fun sum(a: Int, b: Int): Int = a + b`.
- Локальна функція оголошується всередині іншої та доступна в її межах.
- Перевантаження — одна назва функцій, але різна кількість або типи параметрів.
- `(Int, Int) -> Int` — тип функції, яка приймає два Int і повертає Int.
- `::sum` — посилання на функцію; `sum(2, 3)` — її виклик.
- Функція вищого порядку приймає іншу функцію або повертає її.
- Лямбда: `{ a, b -> a + b }`; результат — останній вираз.
- Анонімна функція: `fun(a: Int, b: Int): Int { return a + b }`.

## Контрольні запитання
1. Функція оголошується через `fun`: `fun sum(a: Int, b: Int): Int { return a + b }`.
2. Параметри необов’язкові: функція може мати порожні дужки.
3. Виклик — назва та аргументи в дужках: `sum(2, 3)`.
4. Функції верхнього рівня оголошені поза іншими функціями та класами.
5. Аргументи передаються в дужках за позицією або за іменем; типи мають відповідати параметрам.
6. Значення за замовчуванням задається через `=` і використовується, якщо аргумент пропущено.
7. Іменовані аргументи вказують назву параметра: `name = "Олена"`; дозволяють змінювати порядок.
8. Параметри подібні до `val`: їх не можна переприсвоювати. Це не забороняє змінювати вміст переданого масиву.
9. `vararg` дозволяє передавати довільну кількість аргументів одного типу.
10. Анонімна функція використовує `fun` без назви; лямбда — `{ параметри -> вираз }`. У лямбді результатом є останній вираз. В анонімній функції з блоком результат повертається через `return`, який завершує саме цю функцію.

## Що запам’ятати
- `readln().toInt()` — метод викликається з дужками.
- Під час виклику передаємо значення: `greet("Олена")`, а не `greet(name: String)`.
- Змінні однієї функції недоступні в іншій: потрібні значення передаємо через параметри.
- Якщо функція сама виводить інформацію, зберігати її результат у змінній не потрібно.
- Добуток накопичуємо від 1: `result *= number`.
- Повернену функцію потрібно викликати: `val op = selectOperation("+")`, потім `op(8, 5)`.
- `return` завершує поточний виклик функції; наступні дії в main продовжуються.
