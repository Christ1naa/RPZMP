# Матриця вимог PW04 — актуальний стан після етапів 1–8

Джерело — методичні вказівки `PW_04 RPZMP.pdf`, 137 сторінок, прочитані повністю під час реалізації. Під час аудиту повторно звірено завдання, критерії та домашні завдання на с. 7–14, 19–26, 31–37, 42–49 і варіант на с. 137. Номери нижче — друковані сторінки PDF.

Варіант №1 — «Система прогнозування споживання електроенергії»; розбіжності немає. Окремих числових параметрів/алгоритму для варіанта №1 методичка не задає. Будівлі-споживачі, їх режими та формула прогнозу є задокументованою адаптацією; приклади сонячних станцій належать варіанту №30.

Статуси: **А** — реалізація має автоматичну перевірку (у межах указаного тесту); **К** — підтверджено читанням коду/компіляцією, потрібен runtime-сценарій; **Ч** — частково, є відкрита знахідка; **Д** — потрібні докази/оформлення. Етапи 1–8 мають реалізацію, результати автоматичних перевірок та оригінальні кадри. Фінальний облік — [final-checks.md](final-checks.md): 54 JVM і 64 унікальні Android-методи в кількох конфігураціях. Немокований callback підтверджено через network provider фізичного телефону; окремої верхньої межі віку fix тест не перевіряє; зелений маркер/рух/off-on перевірено через явно позначені системні test providers, без заяви про супутниковий GPS. Подання й захист не виконано. Знахідки — [audit-stage-1.md](audit-stage-1.md); потоки — [stage-2-flow.md](stage-2-flow.md); каталог — [stage-3-catalog.md](stage-3-catalog.md); запити — [stage-4-query.md](stage-4-query.md); фактичні запуски — [verification.md](verification.md).
