# Матриця вимог PW04

Джерело — повністю прочитані методичні вказівки викладача, 137 сторінок. Вказано друковані сторінки PDF. На с. 137 варіант №1 — «Система прогнозування споживання електроенергії», розбіжності немає. Методичка задає спільні рівневі вимоги; окремих числових параметрів для варіанта №1 немає. Приклади варіанта №30 адаптовано до будівель-споживачів, а генерацію замінено прогнозом споживання.
