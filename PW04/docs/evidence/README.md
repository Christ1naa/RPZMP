## Відтворення

Із теки PW04 після запуску AVD, без Maps API-ключа:

```powershell
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest --offline --console=plain
python scripts/collect_evidence.py --serial emulator-5554
```

`--offline` використовувати лише за наявності залежностей у кеші. Скрипт потребує Python 3 (лише стандартна бібліотека), adb із ANDROID_HOME/ANDROID_SDK_ROOT або типового Windows SDK; можна передати --adb. Він установлює APK у вказаний AVD, запускає один EvidenceCaptureTest через am instrument, перевіряє OK (1 test), копіює оригінали з приватного каталогу через run-as і формує manifest. Gradle connected runner зазвичай видаляє пакети, тому цей сценарій запускається напряму до видалення. Лог — у виключеному build/verification/stage8-evidence-instrumentation.txt. Новий збір перезапише ці сім кадрів та manifest актуальними даними; попередньо збережіть їх, якщо потрібна історія.

## Чого ці кадри не доводять

Справжня Google Maps, тайли/маркери/InfoWindow/камера, зелений маркер GPS, системні діалоги coarse/fine/постійної відмови, збій/retry, великий шрифт і орієнтація не зафіксовані цим набором. Для частини цих сценаріїв є окремі автоматичні тести; решта доказів перелічена в [етапі 8](../stage-8-report.md) і [verification.md](../verification.md). Фіктивних зображень для них немає.
