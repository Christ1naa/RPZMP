# EnergyForecast — практична робота №1

Варіант 1: «Система прогнозування споживання електроенергії».

Застосунок реалізує завдання практичних занять 1–4
на просунутому рівні.

## Можливості

- Демонстраційні показники з анімацією.
- Додавання, редагування та видалення електроприладів.
- Перевірка параметрів введення.
- Прогноз добового споживання та споживання за період.
- Графік накопиченого споживання.
- Навчальна реєстрація, вхід і вихід.
- Відновлення стану під час повороту.
- Окремі списки приладів для користувачів у поточному сеансі.

## Модель прогнозування

Добове споживання:

E_day = sum(P_i / 1000 × t_i × q_i)

Споживання за період:

E_period = E_day × D

P_i — потужність одного приладу у ватах;
t_i — години роботи на добу;
q_i — кількість однакових приладів;
D — кількість днів.

Результат вимірюється у кВт·год.

Прогноз передбачає сталу потужність і однаковий режим
роботи щодня. Графік показує накопичене споживання.

## Структура коду

- model — моделі даних.
- logic — розрахунки та перевірка введення.
- data — демонстраційне сховище акаунтів.
- ui/auth — керування станом авторизації.
- ui/components — повторно використовувані компоненти.
- ui/screens — екрани застосунку.
- ui/theme — оформлення.
- src/test — локальні автоматичні тести.
