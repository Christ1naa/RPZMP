# Докази PW05

## Поточні матеріали

Поточний звіт використовує **25 фізичних оригінальних PNG Galaxy A54, Android 16/API 36**: [підписи](galaxy-a54-api36/README.md), [галерея](galaxy-a54-api36/Gallery.md), [manifest](galaxy-a54-api36/manifest.json). Оригінали без обрізання та домальовування; архів — ../PW05_Report_Screenshots.zip. Звук має ручне підтвердження користувача, а не доказ зі скриншота.

Матеріали **Pixel_6 AVD** нижче є історичними; їхні сенсорні значення емульовані. Reboot і forced deep idle мають окремі успішні протоколи, фізичний snooze також підтверджено. Відкриті: вібрація, точність/затримка, natural Doze, повне UI process-death recovery та інші API. Датчик MISSING на Galaxy A54 не імітувався.

Нові raw-протоколи audit-permission-* містять клас/метод і статуси; metadata.json зберігає параметри та хеші APK. Старі короткі протоколи не дають підстав стверджувати виконання всіх поточних методів одним набором.

Наведені в історичному розділі AVD-зображення отримані зі справжнього виконання PW05 на Pixel_6 AVD, Android 16/API 36, 17.11.2026. Сенсори емульовані. Зображення не генерувалися й не домальовувалися. Час у шторці — час емулятора; дата роботи — 17.11.2026, Europe/Amsterdam.

Деякі початкові кадри шторки ще не показують нотифікацій PW05 й не є доказом їхнього показу.

## Протоколи

checks/android-main.xml — остаточна основна Android-регресія.
checks/permission-denied.txt — окремий запуск з pm revoke POST_NOTIFICATIONS.
checks/notification-policy.txt — два окремі тести заблокованого каналу й cooldown на контрольованих fixtures.
checks/TEST-*.xml — unit-результати; checks/lint-debug.xml — повний Lint без приховування попереджень.

Скомпільовані APK та кеші зберігаються лише в ігнорованих build-каталогах. Хеші остаточних звітів і доказів — docs/SHA256SUMS.txt.

## Історичні відкриті докази на етапі AVD

Фізичний телефон і зміна його сенсорів, фізичний звук/вібрація, окрема фотографія відсутнього датчика, reboot, Doze та сценарій завершення процесу з відновленням UI. Немає кадрів API 26/33/37. Ці перевірки не зараховуються як виконані лише на підставі збірки або unit-тестів.
