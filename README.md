# РПЗМП — навчальні записи

## Структура
- `lectures/lecture-XX/notes.md` — коротка теорія, відповіді та команди.
- `lectures/lecture-01/tasks.kt` і `lectures/lecture-02/tasks.kt` — вправи в одному файлі.
- `lectures/lecture-03/task01.kt`–`task05.kt` — окремий файл для кожного завдання.
- `lectures/lecture-01/HelloKotlin/` — проєкт для завдання з IntelliJ.

## Робота
Пишу код у IntelliJ IDEA, компілюю та запускаю через CMD.
Лекції 1–2 компілюю окремо, у лекції 3 — кожен файл завдання окремо.
Команди запуску — в її `notes.md`.
Згенеровані файли та локальні налаштування виключаю через `.gitignore`.

- [x] Лекція 3 — умовні конструкції, цикли, діапазони та масиви.
