# РПЗМП — навчальні записи

## Структура
- `lectures/lecture-XX/notes.md` — коротка теорія, відповіді та команди.
- Лекції 1–2 і 5: `tasks.kt` — усі вправи лекції в одному файлі.
- Лекції 3–4: `task01.kt`–`task05.kt` — окремий файл для кожного завдання.
- `lectures/lecture-01/HelloKotlin/` — проєкт для завдання з IntelliJ.

## Робота
Пишу код у VS Code, компілюю та запускаю через CMD.
Кожну лекцію компілюю окремо, у лекціях 3–4 — кожен файл завдання окремо.
Команди запуску — у відповідному `notes.md`.
Згенеровані файли та локальні налаштування виключаю через `.gitignore`.
